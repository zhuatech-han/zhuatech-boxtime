## 会话与通用规则

同源/api。先GET /auth/csrf取得header/token，写请求带该CSRF头并保留cookie。POST /auth/login输入username/password，GET /auth/me取角色、范围、权限与菜单，POST /auth/logout退出，POST /auth/password输入oldPassword/newPassword修改并退出。敏感口令不在URL。

业务失败返回HTTP400/401/403/409/429及code；不返回SQL或凭证。列表search/status/page/size/sort，page从0起，size1–100，sort为newest或reference。业务命令requestKey是UUID，version是最新记录版本，note为事实证据（最多1000字符）。相同UUID相同完整载荷不重复执行，返回当前记录；改载荷或账号返回REQUEST_KEY_REUSED。不要用新UUID重复支付同一实际款项。

## 目录和约定

GET /options返回范围内客户、可读约定、箱型、部门与公司显示名。POST /customers、PUT /customers/{id}输入name/departmentId/enabled；DELETE删除未引用客户。

GET /agreements分页、GET /agreements/{id}详情、POST新建、PUT草稿修改。字段：reference/customerId/carrier/port/containerType/zone/mode/calendar/includeStart/includeEnd/holidays/validFrom/validTo/freeDemurrage/freeDetention/freeCombined/tierDays，以及demurrageFirst/demurrageAfter/detentionFirst/detentionAfter/combinedFirst/combinedAfter。日期YYYY-MM-DD，holidays是英文逗号分隔日期，money可使用精确十进制字符串。写入还需requestKey，编辑需version。POST /agreements/{id}/commands/approve或cancel：版本、UUID、说明；approve必须不同于createdBy。

## 案件

GET /shipments、GET /shipments/{id}，POST/PUT字段reference/billOfLading/containerNo/agreementId/arrival、requestKey及编辑version。详情含shipment、agreement快照、extensions、payments、paid、calculation和events。DELETE /shipments/{id}使用命令体作废并保留证据（可作废DRAFT/ACTIVE）。

POST /shipments/{id}/commands/{action}：

| action | 附加字段与要求 |
|---|---|
| submit | 草稿启用 |
| gate-out | date，证据note；ACTIVE且未提箱 |
| return | date，证据note；ACTIVE且已提箱 |
| cancel | 证据note；DRAFT/ACTIVE且无待批延期 |
| extend | phase、days、note；ACTIVE/RETURNED |
| approve-extension / reject-extension | extensionId、note；不同申请人 |
| calculate | RETURNED且无待批延期 |
| review | note；CALCULATED且不同核算人 |
| bill | amount、reference、note；REVIEWED |
| revise-bill | amount、reference、note；DISPUTED |
| confirm / dispute | note；BILLED且不同账单录入人 |
| pay | amount、reference、note；ACCEPTED/PART_PAID |
| reverse | paymentId、note；PART_PAID/PAID，不同付款登记人 |

GET /shipments/{id}/preview?asOf=YYYY-MM-DD，返回final、asOf与逐日calculation，未结束箱务为预估。asOf不得早于已登记的箱动态或晚于港口今天。GET /shipments/{id}/report.json和/agreements/{id}/report.json需export及原读取权限，范围一致。

## 管理与统计

GET /dashboard汇总当前可见案件；GET /audit限内部audit岗位，最多500条。GET/POST /admin/{type}、PUT/DELETE /admin/{type}/{id}，type白名单users/roles/permissions/menus/departments/dictionaries/settings。后台要求未绑定客户的ALL管理员。permissions/menus/settings仅编辑已注册项，不允许新增或删除。

users：username/displayName/password/roleId/departmentId/customerId/enabled，编辑password留空保留，customerId空为内部岗位。roles：name/scope/permissions（已注册编码集合）。departments：name。menus：name/nameEn/permissionCode/position/enabled。permissions：name。dictionaries：type/code/name/nameEn（已有type/code不可变）。settings：value，只允许注册timezone固定Asia/Shanghai（事件显示默认值；计费采用各约定zone）、companyName、maxShipments100–1000。
